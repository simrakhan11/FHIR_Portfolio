# Healthcare Interoperability Portfolio 
This repository contains academic practical work demonstrating healthcare data interoperability and API workflows developed in Postman.
## Project: FHIR and openEHR API Workflows
The Postman collection documents structured API requests and responses for academic use. It includes practical workflows related to healthcare data exchange, such as creation and retrieval of clinical data, template-based documentation, structured compositions, and query-based data retrieval.
## Skills demonstrated
- Healthcare interoperability concepts
- REST API testing with Postman
- JSON-based data exchange
- Structured clinical data modelling
- FHIR and openEHR concepts
- Creation, retrieval and query workflows
- Academic use of synthetic data
- ## Tools
- Postman
- HL7 FHIR / openEHR REST APIs
- GitHub
- ## Data protection
- All examples are for academic and portfolio purposes only. The repository must contain no real patient data, passwords, access tokens, API keys, or confidential system information.
